# v0.4.5 Lifecycle, Preflight, and Tunnel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace loose Desktop Host runtime ownership with a single Supervisor, bounded awaited lifecycle, immutable startup preflight, cached Node resolution, and Host-owned tunnel profile materialization/readiness.

**Architecture:** `src/main.cjs` becomes a composition root. `RuntimeSupervisor` owns broker/Agent/tunnel resources; `AppLifecycleCoordinator` owns Electron quit/update continuation; `StartupPreflight` produces one immutable transaction input. Tunnel connection is ready only after `/readyz` 200.

**Tech Stack:** Node.js CommonJS, Electron 40, node:test, OpenAI tunnel-client.

**Spec:** `docs/superpowers/specs/2026-08-28-v0.4.5-runtime-governance-design.md`

## Global Constraints

- Baseline is `97469f91730e26f3cb903e7701c611a794101622`; do not mutate v0.4.4 tags/releases.
- Preserve window-close-to-tray, safeStorage runtime-key behavior, approval boundaries, updater policy, and AppContainer/Seatbelt enforcement.
- `connected` requires Agent health + tunnel `/readyz` 200.
- Start/stop/restart/shutdown are single-owner, single-flight operations.
- No synchronous repeated Node `--version` probes on the Electron main thread.
- Tunnel retry must not blindly run `init --force`.

```js
function createRuntimeSupervisor(deps) {
  let state = 'stopped';
  let startPromise = null;
  let shutdownPromise = null;
  let generation = 0;
  const resources = [];
  async function start() {
    if (shutdownPromise) throw Object.assign(new Error('App is shutting down'), { code: 'APP_SHUTTING_DOWN' });
    if (startPromise) return startPromise;
    startPromise = (async () => {
      const token = ++generation;
      state = 'preparing';
      const preflight = await deps.prepare({ cancelled: () => token !== generation });
      const broker = await deps.startBroker(preflight); resources.push(broker);
      state = 'agent_starting';
      const agent = await deps.startAgent(preflight); resources.push(agent);
      await deps.waitAgentReady(agent, preflight);
      state = 'agent_ready';
      state = 'tunnel_starting';
      const tunnel = await deps.startTunnel(preflight); resources.push(tunnel);
      await deps.waitTunnelReady(tunnel, preflight);
      state = 'connected';
      return getStatus();
    })().finally(() => { startPromise = null; });
    return startPromise;
  }
  function getStatus() { return Object.freeze({ state, connected: state === 'connected' }); }
  return { start, getStatus /* add stop/restart/shutdown during GREEN/refactor */ };
}
```
