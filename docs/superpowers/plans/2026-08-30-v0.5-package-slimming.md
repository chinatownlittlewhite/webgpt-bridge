# WebGPT Bridge v0.5 Package Slimming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce production package size without removing runtime/security behavior, weakening sandbox boundaries, or introducing first-run downloads.

**Architecture:** Keep Electron, bundled tunnel resources, Windows trusted Node runtime, Windows native host, and macOS Universal support intact. Slim only production packaging inputs: derive dev-only Agent exclusions from the lockfile, remove package-manager shims that have no runtime contract, then remove target-irrelevant `node-pty` payload with platform-explicit builder rules. Finish by emitting component-size evidence from release CI rather than introducing a brittle size cap before measurements stabilize.

**Tech Stack:** Electron 40, electron-builder 26.15.3, Node.js 22 CI / Agent Node >=20, CommonJS packaging helpers, `node:test`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-29-v0.5-security-architecture-slim-ui-design.md`

## Global Constraints

- Existing users keep settings, runtime keys, workspace selection, handoff data, and valid Goal state.
- Existing MCP capabilities are not removed merely to reduce package size.
- Shell, privilege-escalation, sensitive-path, sandbox, approval, process-isolation, Host-capability, and broker-auth boundaries are not weakened.
- macOS and Windows remain formal release targets with real packaged acceptance.
- macOS Universal remains available.
- Offline-complete packaged operation is preserved; no first-run dependency downloads.
- No UPX.
- Windows bundled Node runtime, Windows native host preparation, and tunnel payload stay intact in this plan unless a later independently verified task proves a safe replacement.
- Every pruning change must pass Desktop/Agent regression plus packaged macOS PTY and Windows NSIS lifecycle smoke.
