# Stage 13 Capabilities and Diagnostics Contract Implementation Plan

**Goal:** Make Agent `get_capabilities` and trusted Desktop diagnostics expose compatible, allowlisted product facts from one shared metadata source.

**Architecture:** Add a dependency-light shared product contract for version/protocol/Goal facts and a shared metadata projector that combines those facts with the canonical tool registry. Project both shared files into the packaged Agent. Agent capabilities and Desktop diagnostics consume the projector; no caller may pass secrets, environment, broker paths, proxy values, or arbitrary Host paths into the public metadata shape.
