# v0.4.5 macOS PTY Packaging and Artifact Acceptance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make packaged macOS node-pty PTY execution reliable by normalizing `spawn-helper` execute bits before code signing and proving the final artifact with independent inspection + real PTY smoke.

**Architecture:** A narrow payload utility validates and normalizes both Darwin node-pty payloads during electron-builder `afterPack`. A separate read-only final artifact inspector and packaged runtime smoke prevent the normalizer itself from masking release defects.

**Tech Stack:** Node.js CommonJS, electron-builder 26.15.3, node-pty 1.1.0, GitHub Actions macOS universal build.

**Spec:** `docs/superpowers/specs/2026-08-28-v0.4.5-runtime-governance-design.md`

## Global Constraints
- No runtime chmod/self-repair after signing.
- Do not upgrade node-pty solely to solve this mode bug.
- Universal artifact must contain both `darwin-arm64` and `darwin-x64` `spawn-helper` + `pty.node`.
- Missing/symlinked/escaped payload is a build failure.
- Windows PTY behavior and dependency version remain unchanged.
