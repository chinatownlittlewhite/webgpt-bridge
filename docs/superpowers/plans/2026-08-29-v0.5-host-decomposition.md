# WebGPT Bridge v0.5 Host Decomposition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `src/main.cjs` into an Electron composition root by extracting settings/secrets, Host authorization and broker ownership, runtime process orchestration, and window/tray/IPC controllers without changing the v0.4.11-compatible external behavior.

**Architecture:** Keep Electron lifecycle ownership and top-level dependency wiring in `src/main.cjs`. Move stateful business/security responsibilities into focused CommonJS factories under `src/host/`, with explicit dependency injection so unit tests can exercise them without booting Electron. Existing security policy, broker protocol, RuntimeSupervisor, UpdateService, startup preflight, and lifecycle components remain authoritative; this task only changes ownership boundaries and wiring.

**Tech Stack:** Electron, Node.js CommonJS, `node:test`, existing WebGPT Bridge Host/Agent modules.

**Spec:** `docs/superpowers/specs/2026-08-29-v0.5-security-architecture-slim-ui-design.md`

## Global Constraints

- Existing users upgrade without resetting settings, runtime keys, workspace selection, handoff data, or valid Goal state.
- Existing MCP capabilities are not removed merely to simplify implementation or reduce package size.
- Existing shell, privilege-escalation, sensitive-path, sandbox, approval, and process-isolation boundaries are never weakened.
- macOS and Windows remain formal release targets with real packaged acceptance.
- Renderer modernization remains out of scope for this stage.
- No new runtime dependency is introduced.
- `src/main.cjs` remains the owner of Electron App/profile startup, single-instance ownership, service construction, top-level controller registration, and start/shutdown lifecycle wiring.
- Existing v0.4.11 migration and release compatibility remain intact.
