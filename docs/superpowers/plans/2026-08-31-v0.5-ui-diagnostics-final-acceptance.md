## Global Constraints

- Sensitive filesystem, terminal, shell, SSH, GitHub CLI, credential, and process operations remain Host-owned and fail closed.
- Renderer and preload receive only bounded structured diagnostics; no raw tokens, secrets, arbitrary subprocess output, or model-controlled Host grants cross the boundary.
- Project sandbox remains default-deny; path comparison is canonicalized before authorization.
- Frozen approvals remain isolated from later request mutation.
- Goal Store v2 and crash-recoverable file transactions remain unchanged and recoverable.
- MCP remains first-class with the canonical declarative 26-tool contract.
- WebSocket/log buffering remains bounded and incremental updates must not freeze the Renderer.
- macOS Universal remains the updater source; arm64/x64 alternatives and target-specific native payload pruning from Step 12 remain intact.
- Package-size reports and `max(5%, 5 MiB)` previous-formal-release budgets remain enforced.
- No first-run dependency downloads, UPX, or weakened signing/notarization/release validation.
- Temporary CI surfaces are removed before integration; integration is fast-forward only, without force.
